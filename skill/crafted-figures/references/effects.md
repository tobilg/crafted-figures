# Hybrid effects

Use `kit.effects.effect(name,{kind,size,layer,intensity,theme,quality})` for bounded glow/spark planes, fire/steam volumes, water and caustic surfaces or a constrained illustrative shadow. Place it with native Three transforms in the same stage scene as the opaque geometry. `kit.effects.fallback(illustratedObject,effectName)` identifies a meaningful vector fallback, excluded from GPU depth. Attach fallback/effect to the same native parent when they move together.

Mount with `kit.effects.mountEffects(root,stage,config)` after the SVG view. Call `effects.render(modelTime)` after each displayed-state update; it owns no animation loop. Always dispose it before the stage. The shipped hybrid template shows the lifecycle, shared clock and intensity uniforms. `rendering.effects: off` selects vector output. Context loss deliberately remains in fallback with usable controls.

Each numbered effect layer owns a transparent canvas and a matching depth pass of actual opaque meshes. Surface recipes retain that depth; volumes read the depth texture and terminate orthographic ray integration at the solid. Solid parents remain visible to traversal with depth-only materials, so their attached emitters can render. This is not shared depth with SVG. SVG painter ordering must pass independently.

Alpha output is premultiplied and RGB already includes alpha. Volumes integrate once through back faces and fade before box edges; avoid multiplying alpha twice. Light/dark palettes differ intentionally. DPR defaults to 1.5, bounded by validated config; draft uses 24 volume samples versus 48 standard. Draft is not final parity evidence.

These are constrained illustration recipes, not arbitrary shader conversion, transparent-mesh sorting, fluid simulation or universal occlusion. The water recipe uses a Fresnel-weighted analytic sky reflection and wave-normal refraction of a declared planar tile pattern, plus a receiving-plane focusing approximation and model-derived illustrative shadow. It does not refract arbitrary scene objects or sample external images. Supply the same emission history to water and caustics with `surfaceHistory(effect, [{x,y,age,amplitude}])`: up to eight events, normalized surface coordinates in [-1,1], seconds since emission, amplitude in [0,1]. Events fade to zero by 3.5 s. The ripple-tank pure model replays two emitters deterministically; all optical terms and float position follow that model. Review registration with actual GPU pixels, hidden/crossing/front states, volume bounds, both themes, real context loss and resize. Compilation alone is not acceptance. Numbered SVG/canvas placement is supported within the physically ordered layer contract below.

Use `kit.effects.svgPass(object, {afterLayer: 0})` to place a solid or assembly's vector art after canvas layer 0 and before layer 1. The assignment inherits through the Three hierarchy; the compositor moves the existing keyed SVG nodes into aligned SVG passes. All passes share the stage camera and sizing. The renderer rejects a pass assignment that reverses the ray-tested near/far relation of two opaque solids (`SVG_LAYER_ORDER`). Declare physically coherent layers; this is not an arbitrary z-index escape hatch. On initialization failure or context loss all vector parts return to the base SVG. The ripple-tank recipe places a submerged scale between caustic and water passes and the rim/float after water.

The turning-mechanism template gives released sparks and the light pool their own model-driven vector symbols alongside the lamp. Static SVG and WebGL failure/context loss retain these explanatory elements. Use the same release-time and intensity model for both paths; do not approximate release by attaching particles to the moving source. See the installed `drive` effect/context-loss operations in [verification.md](verification.md) to check each family explicitly.

At a particle's exact birth its SVG glyph may still be inside the physical lamp core. The template represents that emission with the core, then grows a distinct glyph only within its measured clearance from the tool/lamp envelope. The model position is unchanged; no camera-facing displacement or painter bias is applied. This qualified emitter recipe is not general SVG clipping of arbitrary particle volumes.
